- `app.dart` — MaterialApp, LocaleScope, localization delegates (includes the
  official Global* delegates, required so built-in widgets work in ur/ar).
- `localization/` — AppLocalizations + en/ur/ar string maps. All sections now use `t('key')`.

## Regional sites (content/)
- `content/{pk,us,ae}` — region-specific Jekyll (minima) content.
- `content/common` — shared files merged into every region at deploy time
  (region files win on name collisions). Reference as `/assets/logo.png`.

to generalsoft/nasim-{pk,us,ae} using the `REGIONAL_SITES_PAT` secret.
