# abidnasim.com — project snapshot

## Flutter app (lib/)
- `app.dart` — MaterialApp, LocaleScope, localization delegates (includes the
  official Global* delegates, required so built-in widgets work in ur/ar).
- `localization/` — AppLocalizations + en/ur/ar string maps. All sections now use `t('key')`.
- `widgets/`, `pages/`, `services/`, `constants/` — as planned.
- `pubspec.yaml` — adds `flutter_localizations` (sdk: flutter).

## Regional sites (content/)
- `content/{pk,us,ae}` — region-specific Jekyll (minima) content.
- `content/common` — shared files merged into every region at deploy time
  (region files win on name collisions). Reference as `/assets/logo.png`.

## CI (.github/workflows/flutter-web.yml)
Builds/deploys the Flutter site, then pushes each region (common + region folder)
to generalsoft/nasim-{pk,us,ae} using the `REGIONAL_SITES_PAT` secret.

## nasim.ae (Arabic) import
Source: https://github.com/generalsoft/nasim-ae (`src/content/{work,blog,hobby}/*-ar.md`, `src/pages/ar/*`).
- `content/ae/_posts/` — 13 posts (8 work, 4 blog, 1 hobby) with real `publishDate` and tags from the Astro source.
  Front matter: title, description, date, tags, section (work|blog|hobby), image, image_alt, permalink.
- `content/ae/{index,about,contact,work,blog,hobby}.md` — landing, about, contact and section listings.
- `content/ae/assets/` — the 17 image files referenced by the imported content (paths unchanged).
- `content/common/_layouts/post.html`, `_includes/post_list.html`, `_sass/site-extras.scss` — shared by all regions.
- URLs changed: `/ar/work/<slug>-ar/` is now `/work/<slug>/` (same for blog, hobby).

Not imported: the contact form (Firebase config lives in an untracked .env), dark-theme toggle,
image carousel, and the English pages of nasim.ae.
