{%- comment -%} Contact form → Firestore. Shared by nasim.pk / nasim.us / nasim.ae (merged in from content/common at deploy time). Include it from a region's contact.md: {% include contact_form.html %} It writes the same document shape as the Flutter app's contact form (lib/services/contact_service.dart) into the same collection, so every surface feeds one inbox: name, email, message, source, locale, pageUrl, createdAt The Firebase config is NOT committed. The deploy workflow writes `assets/js/firebase-config.js` (window.FIREBASE_CONFIG) from the PUBLIC_FIREBASE_* secrets just before `jekyll build`; locally, create that file yourself (see .env.example). Without it the form renders disabled with the "unavailable" message — a build without secrets degrades to the email links instead of pretending to send. Wording comes from `contact_form:` in each region's _config.yml, with English fallbacks here so the form is never blank. {%- endcomment -%} {%- assign form = site.contact_form -%}
